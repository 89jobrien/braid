Guardrails

  • GitHub issue state is authoritative for implementation status.
  • Completed capabilities are not recreated because an older checklist is stale.
  • Braid does not become CI/CD, a distributed scheduler, or an unbounded autonomous agent.
  • Material scope changes update both the issue and the repository roadmap.
