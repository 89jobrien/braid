Braid Overview Architecture Crates Safety Testing Roadmap Changelog

Trust boundaries

Safety is layered, not implied.

Redaction protects data crossing model boundaries. Hooks govern requested actions. Storage preserves evidence. Each layer has a separate job and a visible seam.

Redaction before exposure

The engine maps provider-bound messages through the injected Redactor before calling Provider::complete. Tool results are converted into messages and redacted before they re-enter the transcript.

Ordered rules

RedactionPipeline

Composes secret-pattern, environment-variable, and home-path rules in registration order.

Boundary contract

Redactor

Keeps the engine generic while making message scrubbing an explicit runtime dependency.

Known gap: event persistence does not yet have one guaranteed redaction boundary. That hardening work is tracked in roadmap epic #42.

Hooks around execution

HookedExecutor evaluates registered pre-hooks before dispatching a tool. A deny verdict carries both a reason and remediation. Successful execution is followed by post-hooks, keeping policy outside tool business logic.

StageContractResult
BeforeHook::pre_executeAllow or deny with actionable context
ExecuteToolExecutor::executeStructured tool result or propagated error
AfterHook::post_executeExternal observation or follow-up policy

Hardening before autonomy

The first roadmap epic closes concrete safety gaps before Braid adds review loops, worktrees, or scheduled agents.

  • Persistence: make redact-before-persist unavoidable and regression-tested.
  • Paths: contain session and component paths beneath configured roots.
  • Concurrency: partition buffered events by session.
  • Protocol: reject oversized MCP frames before payload allocation.
  • Tools: advertise the definitions available to the engine.
  • Tests: remove process-global environment races.

Workspace policy

Compiler boundary

unsafe_code = "deny"

The workspace denies unsafe code. Narrow test modules that must mutate process environment carry explicit allowances.

Dependency boundary

cargo xtask check-deps

CI checks forbidden cross-crate edges so the dependency rings remain enforceable.
