Workspace inventory

Thirteen product crates. One direction of travel.

Each crate has a narrow responsibility. Shared values and contracts sit inside; integrations and operator surfaces sit outside.

Inner rings

Domain leaf

braid-model

Canonical messages, content parts, tool calls, provider data, events, sessions, transcripts, tasks, and context types.

Ports

braid-ports

Provider, tool, redaction, event, storage, context, hook, and component contracts. Depends only on the model crate internally.

Application core

braid-engine

The generic agent loop, planner boundary, session state, tool registry, and runtime lifecycle events.

Depends inward on braid-ports and braid-model.
