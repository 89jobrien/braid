Quality gates

Test the contracts, not just the happy path.

Fast local gates cover formatting, lints, architecture, and behavior. CI adds provider, coverage, dependency, and end-to-end checks around the same workspace.

Local gate

$ cargo fmt --all
$ cargo clippy --workspace -- -D warnings
$ cargo nextest run --workspace

The repository's just pre-commit workflow also includes a release build. Nextest is the preferred runner for parallel workspace tests.

Isolation rules

Tests receive temporary directories through dependency injection. Process environment mutation must be restored, and tests are expected to remain safe under nextest's parallel execution model.

The roadmap's foundation epic explicitly includes the remaining environment-isolation hazards and concurrent session-storage behavior.
